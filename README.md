# Provenancy — Backend API

Provenancy is a work verification platform where students log internship and freelance engagements, and supervisors cryptographically verify them, generating a tamper-evident credential ledger. Built as a college group project.

---

## Tech Stack

| Concern          | Technology                        |
| ---------------- | --------------------------------- |
| Language         | Python 3.13                       |
| Framework        | FastAPI                           |
| Database         | PostgreSQL (Supabase)             |
| ORM              | SQLAlchemy                        |
| DB Driver        | psycopg (psycopg3)                |
| Auth             | JWT (HS256) via `python-jose`     |
| Password Hashing | passlib + bcrypt                  |
| Deployment       | Render                            |

---

## Project Structure

```
provenancy_backend/
├── app/
│   ├── main.py          # App entry point, middleware, router registration
│   ├── config.py        # Settings loaded from environment variables
│   ├── database.py      # SQLAlchemy engine and session setup
│   ├── models.py        # ORM models (User, StudentProfile, Engagement, etc.)
│   ├── schemas.py       # Pydantic request/response schemas
│   ├── auth.py          # JWT token creation and verification
│   └── routes/
│       ├── student.py       # Student profile routes
│       ├── supervisor.py    # Supervisor profile routes
│       ├── engagements.py   # Engagement CRUD + verification routes
│       └── skills.py        # Skills search and management
├── requirements.txt
├── Procfile             # Render deployment config
└── .env                 # Environment variables (never commit)
```

## Prerequisites

- Python 3.13+
- A running PostgreSQL database (Supabase recommended)
- `pip` / `pip3`

## Environment Setup

Create a `.env` file in the project root:

```env
# Database (Supabase)
user=your_db_user
password=your_db_password
host=your_supabase_host
# Database (Supabase)
# Use port 6543 if connecting via connection pooler (recommended)
# Use port 5432 for direct connection
port=6543
dbname=postgres

# App
PORT=8000
DEBUG=False

# Auth
SECRET_KEY=your_secret_key_here
ACCESS_TOKEN_EXPIRE_MINUTES=10080

# CORS — comma-separated list of allowed frontend origins
ALLOWED_ORIGINS=http://localhost:5173,https://your-frontend.vercel.app
```

> **Generate a secure `SECRET_KEY`:**
> ```bash
> python3 -c "import secrets; print(secrets.token_hex(32))"
> ```

## Installation & Running Locally

### macOS / Linux

```bash
pip3 install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### Windows

```bash
pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8000
```

The API will be available at `http://localhost:8000`.

## API Reference

Interactive Swagger docs are auto-generated by FastAPI and available at:

```
http://localhost:8000/docs
```

For the full endpoint reference including request/response schemas, error codes, and field-level documentation, see [`API_DOCUMENTATION.md`](./API_DOCUMENTATION.md).

### Key Endpoints at a Glance

| Method | Endpoint           | Description                        |
| ------ | ------------------ | ---------------------------------- |
| `GET`  | `/health`          | Health check (API + DB status)     |
| `POST` | `/auth/register`   | Register a new student/supervisor  |
| `POST` | `/auth/login`      | Login and receive JWT token        |
| `GET`  | `/auth/me`         | Get current user + profile         |
| `GET`  | `/student/me`      | Get student private profile        |
| `GET`  | `/supervisor/me`   | Get supervisor private profile     |
| `POST` | `/engagements`     | Create a new engagement (student)  |
| `GET`  | `/skills/search`   | Search skills (`?q=python`)        |

## Deployment

This project is deployed on **[Render](https://render.com/)** using the `Procfile`:

```
web: uvicorn app.main:app --host 0.0.0.0 --port $PORT
```

The database is hosted on **[Supabase](https://supabase.com/)** (PostgreSQL).  
The frontend is deployed separately on **[Vercel](https://vercel.com/)**.

> Ensure all environment variables from the `.env` section above are configured in your Render service's environment settings before deploying.
